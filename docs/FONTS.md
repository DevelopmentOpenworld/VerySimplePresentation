# VerySimplePresentation: шрифты — откуда сервис их берёт и что записывает

Состояние на 29.09.2026. Сервис работает на своём сервере, поэтому опознать и подключить шрифты шаблона — его задача. PPTX всегда называет шрифт шаблона. Файл шрифта нужен для другого: нарисовать предпросмотр, HTML и PDF и измерить, помещается ли текст.

## Порядок источников

Для каждой гарнитуры, которую называет шаблон (тема, слайды, макеты, мастера; латиница, восточноазиатские и сложные письменности), сервис идёт по источникам сверху вниз.

| № | Источник | Код в описи | Что попадает в PPTX |
|---|---|---|---|
| 1 | Шрифт, встроенный в сам шаблон | `embedded` | Файл шаблона — как в шаблоне |
| 2 | Закреплённый офлайн-набор продукта (`assets/fonts`): Roboto, Open Sans, Montserrat | `pinned-asset` | EOT того же файла; с 29.09 и в PPTX на образце |
| 3 | Шрифт из контент-пакета пользователя | `content-package` | Не встраивается: лицензия чужая |
| 4 | Та же гарнитура из открытых шрифтов сервера | `catalog` | С 29.09: статическое начертание того же семейства встраивается в PPTX на образце; переменное — нет, с отметкой в `export.json` |
| 5 | Метрически совместимая открытая замена | `metric-substitute` | Не встраивается |
| 6 | Нет нигде | `unavailable` | Имя шрифта шаблона; браузер рисует подстановку |

**Встроенные шрифты.** Используются, если разрешение встраивания (fsType) — «устанавливаемый» (0) или «редактируемое встраивание» (8). Второе допускается так: шрифт загружается только для отрисовки своего документа и производных от него, не устанавливается и не публикуется. «Только просмотр и печать» (4), «ограниченный» (2) и «только растровые образы» отвергаются.

Встроенные шрифты PowerPoint сжаты (MicroType Express). Их распаковывает собственный декодер сервиса (`vsp_core/mtx.py`, по спецификации W3C) одинаково на Windows и Linux; результат хранится по SHA-256 части шаблона в `var/generator/cache/fonts`, повторная загрузка того же шаблона не распаковывает заново. На шрифтах корпуса, которые может загрузить Windows, декодер совпал с ней во всех таблицах и всех знаках. Урезанный встроенный шрифт (в нём только знаки исходной презентации) используется; знаки нового текста, которых в нём нет, перечисляет находка `SUBSET_FONT_MISSING_GLYPHS` — их рисует другой шрифт.

**Встраивание в PPTX (с 29.09.2026).** PDF и HTML рисуются теми же файлами шрифтов, что и замер вместимости; чтобы PowerPoint переносил строки так же, в PPTX на образце встраиваются статические открытые начертания, которыми нарисована колода под именем гарнитуры шаблона (источники 2 и 4), если шаблон не встраивает эту гарнитуру сам. Формат — EOT с заголовком, который пишет сам PowerPoint (версия 0x00020002), без сжатия. Прежний заголовок версии 1 библиотека встраивания шрифтов Windows не читала — встроенный шрифт PPTX без образца с 18.09 не работал. Не встраиваются: метрические замены (в PPTX остаётся Calibri или Arial, они есть у зрителя, ширины знаков те же), шрифты контент-пакета, переменные шрифты. PowerPoint 2013 на машине разработки (15.0.4454) не рисует ни одного встроенного шрифта, даже встроенный самим PowerPoint Play шаблона A; встраивание проверено библиотекой Windows (`t2embed`).

**Метрически совместимые замены** — те же ширины знаков, поэтому совпадают и переносы строк:

| Шрифт шаблона | Замена |
|---|---|
| Calibri | Carlito |
| Arial, Helvetica | Arimo |
| Times New Roman, Times | Tinos |
| Courier New, Courier | Cousine |
| Cambria | Caladea |
| Georgia | Gelasio |

Рисунок букв близок, но не одинаков. Замена без кириллицы не используется: текст сервиса русский, а кириллицу нарисовал бы следующий шрифт под именем шрифта образца. Поэтому Caladea (Cambria) и Gelasio (Georgia) сейчас не подставляются, в описи это видно как `substitute_without_cyrillic`. Список — `profiles/mvp/fonts.json`, ключ `substitutes`.

**Капитель.** Своих глифов капители (`smcp`) у Carlito нет, у Calibri есть. Браузер синтезирует капитель иначе, чем PowerPoint 2013, и проверка вместимости может ошибиться на заголовке, набранном капителью: так было на обложке office-training, где заголовок 40 пт в PowerPoint не поместился. Исправляется отрисовкой капители как в PowerPoint.

**Имя с начертанием.** Шаблон может называть гарнитуру вместе с весом: «Open Sans Light», «Montserrat ExtraBold». Такое имя ищется как отдельное семейство статической сборки. Если его нет, ищется семейство без слова веса в этом весе. Другой вес не подставляется.

## Открытые шрифты сервера

- **Где лежат.** Каталог `var/fonts` вне Git. Другие каталоги задаёт ключ `font_dirs` в `config.json` или переменная `VSP_FONT_DIRS`. Её пути разделяются как `PATH`, и она заменяет значение по умолчанию.
- **Опись каталога.** В каждом каталоге — `index.json`. По каждому начертанию: семейство, полное имя, вес, курсив, fsType, диапазон веса переменного шрифта, есть ли кириллица, SHA-256 файла, лицензия.
- **Файл закрепления** — `profiles/mvp/fonts.json`. В нём репозиторий `google/fonts`, закреплённый коммит и список файлов каждого набора с размером и идентификатором Git. Скачанный файл сверяется с этим коммитом побайтно.

```
python -X utf8 -B scripts/fetch_fonts.py fetch substitutes   # замены шрифтов Microsoft, 25 файлов, 7,6 МБ
python -X utf8 -B scripts/fetch_fonts.py index --dest <каталог>   # опись любого каталога шрифтов
```

Во время генерации сервис шрифты не скачивает.

**Объёмы Google Fonts** на 25.09.2026:
- вся коллекция — 2,2 ГБ;
- без китайских, японских и корейских шрифтов — 851 МБ;
- с кириллицей — 283 МБ.

В образ входит набор замен; с 27.09 закреплён и набор `catalog` — 1805 семейств без китайских, японских и корейских, 5642 файла, 859 МБ с текстами лицензий, каждый файл сверяется с закреплённым коммитом; ставится одной командой в отдельный том сервера (`scripts/fetch_fonts.py fetch catalog --dest <том>`), в образ не входит.

**Шрифты Microsoft по их лицензии** (Verdana, Trebuchet MS, Arial Black, Georgia и другие). Ставятся на сервер установщиком Microsoft с явным принятием лицензии. По умолчанию установка выключена; включается аргументом сборки `MS_CORE_FONTS_EULA=accept`, установленный каталог подключается через `font_dirs`.

## Что записывается

- **`style.json` запуска, ключ `font_inventory`.** Каждая гарнитура: письменности, где названа (с числом ссылок), сколько знаков текста слайдов ею набрано, источник, чем нарисована. Встроенные файлы: сжат ли, урезан ли, fsType, и почему не использован (`embedded_not_used`).
- **`run.json`, ключ `fonts`.** Гарнитура и её источник.
- **Журнал загрузок `var/generator/uploads.jsonl`**, одна строка на событие:
  - `upload`: время, запуск, состав, имя файла шаблона, его SHA-256 и размер, где он сохранён; файлы контент-пакета с SHA-256;
  - `fonts`: опись шрифтов, встроенные файлы, каталоги шрифтов сервера, недоступные гарнитуры;
  - `done`: успех или ошибка.

  Журнал и загруженные файлы остаются на сервере и в репозиторий не попадают.
- **`run.json`, ключ `subset_font_gaps`** — знаки нового текста, которых нет в урезанных встроенных шрифтах.
- **Находки разбора**:
  - `CATALOG_FONT` — та же гарнитура с сервера;
  - `METRIC_SUBSTITUTE_FONT` — метрически совместимая замена;
  - `FONT_NOT_ON_SERVER` — шрифта нет нигде;
  - `SUBSET_FONT_MISSING_GLYPHS` — во встроенном урезанном шрифте нет знаков нового текста;
  - `PINNED_FONT_ASSET`, `PACKAGE_FONT`, `FONT_AVAILABILITY` — как прежде ([AUDIT](AUDIT.md)).
