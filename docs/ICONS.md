# VerySimplePresentation: пиктограммы из самого образца

Пиктограммы сервис берёт из самого образца: размечает по смыслу один раз на образец, выбирает по теме пункта, а при отсутствии подходящей оставляет слайд без пиктограммы. Внешний набор пиктограмм не используется. Состояние на 29.09.2026.

## Как устроено


| Шаг | Где | Что делает |
|---|---|---|
| Каталог | `vsp_core/icons.py`, `read_icons` (из `importer.read_style`) | PNG со слайдов-образцов: до 3 % площади слайда, стороны 16–512 px, пропорции 0,6–1,67, не повторяющаяся «мебель» (логотипы, полосы), одноцветные — не меньше 90 % непрозрачных пикселей у основного цвета — и не залитые целиком (покрытие до 85 %) |
| PNG без зависимостей | `vsp_core/png.py` | разбор PNG (все фильтры строк; серый, RGB, RGBA, палитра 1–8 бит, tRNS), цвет пиктограммы, перекраска с сохранением прозрачности, поля до нужных пропорций |
| Места | `icons.card_icon_slots`; `sample_clone._unit_set` | в карточке образца — её член с картинкой каталога; **единицы «пиктограмма + текст»** без контейнера (например, шаблон C, слайды 26–28) — новый вид образца `kind: units` |
| Разметка | агент `icon_tagger` v1, пачки по 24 изображения | вид (`icon`, `marker`, `logo`, `shape`, `number`, `other`), смысл, ключевые слова; ответ живой модели кешируется в `var/generator/cache/icon_tagger/<sha256 запроса>.json` — запрос зависит только от картинок образца; записанные ответы (`replay`) кеша не требуют |
| Выбор | агент `icon_picker` v1, один вызов на бриф и образец | пиктограмма каждому пункту слайда или ни одному; только предложенные (`kind: icon`), без повторов на слайде; нарушивший слайд остаётся без пиктограмм |
| Применение | `icons.card_icons`, `sample_clone.card_elements`, `composer` | в карточке — выбранная пиктограмма вместо пиктограммы образца, **в её цвете** и её рамке; в варианте 1 «колонки» раздел, где пиктограмма есть у каждого факта, встаёт на ряд единиц образца раньше плейсхолдеров макета |
| Экспорт | `carrier_export.export_carrier_pptx` | новый медиафайл `ppt/media/…-<sha12>.png`; у заменённой картинки снимаются `srcRect` и `extLst` (SVG-версия старой пиктограммы) |

Где пиктограммы не появляются: образцы без мест под пиктограммы, слайды таблиц, графиков, ключевых чисел и процессов, слайды с одним фактом, варианты 2 «блоки образца» и 3 «иллюстрации образца» у шаблонов без карточек с пиктограммами.

**Почему перекраска допустима.** Пиктограмма берётся из самого образца и получает цвет той пиктограммы образца, место которой занимает; новых знаков и цветов вне шаблона не появляется.

**Вопрос 6 контекстуального аудита** (`image_auditor`) видит выбранные пиктограммы как картинки рядом с фактами и отвечает, относятся ли они к пункту; «нет» становится находкой, как у любой картинки.

## Замер

Каталог одноцветных PNG слайдов-образцов собственным разбором PNG: 352 PNG трёх шаблонов — 0 расхождений с Pillow по пикселям; шаблон A — 27 пиктограмм, шаблон B — 10, шаблон C — 214. Регрессия на 15 колодах сторонних шаблонов и свободных брифах на шаблонах A, B, C: 64 пиктограммы на 31 слайде, вопрос 6 контекстуального аудита — 0 ответов «не относится к теме» о пиктограммах. Разметка и выбор в этом замере — записанные ответы модели разработки, не Qwen3.8-27B.

## Ограничения

- Единицы «пиктограмма + текст» используются только в варианте «колонки»; столбцы единиц найдены, но не используются.
- Одноцветность — условие перекраски; многоцветные пиктограммы и SVG без PNG в каталог не входят.
- Качество разметки и выбора измерено на записанных ответах модели разработки, не на Qwen3.8-27B.
